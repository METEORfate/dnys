## 本次操作

实现显式 assistant-only labels，移除训练正确性对 chat template generation markers 和 TRL assistant_only_loss 自动 mask 的依赖。

## 修改内容

- `training/loss_mask_utils.py`：新增 prompt/full 严格前缀校验、显式 labels 构造、padding collator；截断后重新渲染并拒绝 assistant target 或不可压缩上下文超预算样本。
- `training/train_lora.py`：训练数据预处理直接生成 `input_ids`、`attention_mask`、`labels`；关闭自动 `assistant_only_loss`，使用显式 data collator，关闭 packing。
- `training/inspect_loss_mask.py`：改为复用真实训练路径的截断、prompt/full 渲染和显式 labels 检查。
- `training/test_loss_mask.py`、`training/test_truncation.py`：覆盖严格前缀、system/user -100、assistant 有效 labels、截断后 labels、前缀不一致拒绝和 assistant 超预算报告。

## 修改原因

实例检查确认当前 Qwen tokenizer 没有 `{% generation %}` / `{% endgeneration %}`，`return_assistant_tokens_mask=True` 返回全零 mask。训练必须显式定义监督区域。

## 测试结果

11 个自动测试全部通过；py_compile 和 help 命令通过；fake dataset smoke test 确认输出包含 `input_ids`、`attention_mask`、`labels`，labels 前缀为 -100、assistant suffix 有效。
