## 本次操作

修复 torchrun 双 GPU 下 QLoRA 4-bit 模型的 rank-local device placement。

## 修改原因

原训练脚本未读取 LOCAL_RANK，量化模型可能默认加载到 GPU0，导致 rank1 训练进程与模型设备不一致。

## 涉及文件

- training/train_lora.py
- training/test_train_lora_device.py
- sanlogs/log_20260926_220447_local.md

## 修复方式

- 读取并校验 LOCAL_RANK。
- 模型加载前执行 	orch.cuda.set_device(local_rank)。
- 4-bit 模型使用 device_map={"": local_rank}。
- 保留 BitsAndBytesConfig 和 prepare_model_for_kbit_training()。
- 未使用 device_map="auto"，未修改 LoRA、数据或训练目标。

## 测试方式

- python -m py_compile training/train_lora.py training/test_train_lora_device.py
- python training/test_train_lora_device.py
